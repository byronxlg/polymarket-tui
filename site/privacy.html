Privacy policy

polymarket-tui — last updated 2026-08-10

The application

polymarket-tui is an open-source terminal client for Polymarket. It runs entirely on your machine. It does not operate any backend service, does not collect analytics or telemetry, and does not transmit your data anywhere except to the Polymarket APIs you ask it to talk to. Credentials you configure are stored in a local file on your machine and sent only to Polymarket's services to authenticate your own requests.

This website

This is a static site. It sets no cookies, runs no analytics, and loads no third-party resources. Hosting infrastructure (GitHub Pages) may log requests, including IP addresses, per GitHub's privacy statement.

YouTube publishing automation

The project runs an automation that uploads short demo videos to the project's own YouTube channel via the YouTube Data API. This automation is used only by the project maintainer against the maintainer's own channel.

  • It accesses Google user data solely to upload videos to, and manage metadata on, the authorised channel. It does not read subscriber data, comments, or any other account information.
  • No Google user data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • OAuth tokens are stored in a private secrets manager, are never committed to the repository, and can be revoked at any time at myaccount.google.com/permissions.
